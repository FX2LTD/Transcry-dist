# Transcry — public distribution

Public assets for **Transcry**, a private voice-to-text app for Android by
FX2 Information Services Limited. The app source lives in a private repository;
this repo hosts the public website, legal pages, and the sideloadable APK.

## Links

- **Device compatibility:** https://fx2ltd.github.io/Transcry-dist/devices.html
- **Privacy policy:** https://fx2ltd.github.io/Transcry-dist/privacy.html

- **On Google Play:** https://play.google.com/store/apps/details?id=it.fx2.transcry

## Transcription modes

Transcry transcribes three ways:

- **On-device** — private and offline; runs a speech model on your device. The
  most demanding mode; may not run on entry-level hardware (see
  [Device compatibility](https://fx2ltd.github.io/Transcry-dist/devices.html)).
- **Live** — uses the device's own speech recognizer. Works on nearly all devices.
- **Online** — uses your own API key (Groq / OpenAI / AssemblyAI).

Releases here are the sideloadable build; the app's in-app updater checks this
repo's releases.
